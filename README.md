問A.12(p.188): 二項定理の行で係数 k! が抜けています。
	•	誤: (z+w)^k = Σ_{m=0}^k k!/(m!(k−m)!) z^m w^{k−m} = Σ_{m+n=k} (1/m!) z^m (1/n!) w^n
	•	正: (z+w)^k / k! = Σ_{m+n=k} (1/m!) z^m (1/n!) w^n
	•	このままでは最終行の (1/k!)(z+w)^k につながりません。

1つ目の等号(二項定理)は正しく、問題は2つ目の等号です。k!/(m!(k−m)!) の k! を落として (1/m!)(1/n!) にしているので、等号が成り立っていません。実際は

Σ_{m=0}^k [k!/(m!(k−m)!)] z^m w^{k−m} = k! · Σ_{m+n=k} (1/m!) z^m (1/n!) w^n

左辺を変える(私の最初の提案): 両辺を k! で割って
(z+w)^k / k! = Σ_{m=0}^k [1/(m!(k−m)!)] z^m w^{k−m} = Σ_{m+n=k} (1/m!) z^m (1/n!) w^n
となり、頭の「(z+w)^k」を「(z+w)^k/k!」に、中央の k! を消します。
右辺を変える: 最右辺を k! · Σ_{m+n=k} (1/m!)z^m(1/n!)w^n と書く。ただしこの場合、後の「Σ 1/k! (z+w)^k」へのつなぎが少し回りくどくなります
